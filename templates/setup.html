Training-free anonymization of driving data with SAM 3 and SAM 3D Body. A run needs one GPU (24 GB, CUDA 12.6), the two model submodules, the Python environment and the gated SAM 3 and SAM 3D Body checkpoints (request access on Hugging Face, then uv run hf auth login). Anonymize PP4AV and score it (paper, Table I)

uv run python blur_data/scripts/blur-data-anonymize.py \
    --config configs/anonymize.yaml --dataset pp4av --run pp4av-ours
# PP4AV boxes enclose the whole head: grow the face regions by 1/0.735
uv run python blur_data/scripts/blur-data-derive-run.py \
    --src pp4av-ours --dst pp4av-ours-grow --grow-faces 1.3605
uv run python blur_data/scripts/blur-data-paper-eval.py \
    --gt pp4av --runs ours=pp4av-ours-grow --out outputs/eval/pp4av.json

Anonymize a folder of your own images

uv run python -m blur_data.web        # http://127.0.0.1:5010

The full app picks an image folder, runs the pipeline with live progress and lets you review every region of the result (before | after viewer, statistics, side-by-side comparison of runs).

    --config configs/generate-pp4av.yaml --track-scale 2.0
